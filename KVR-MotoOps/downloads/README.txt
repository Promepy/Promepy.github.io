MotoOps India attendance pilot

Install MotoOps-India-Attendance-0.2.0-arm64.apk on an ARM64 Android 13+ phone. It installs separately as MotoOps India Test. Sign in using your MotoOps India account. A manager with Attendance access must configure store pins, rules, enrollment and salaries first. Allow precise location when starting attendance and keep the visible duty service available.

Check-in requires internet. During duty, encrypted observations queue across short internet outages; checkout stops collection locally and syncs when connected. Force-stop, reboot and vendor battery restrictions can interrupt tracking and create unknown periods. Restore monitoring from Profile when needed.

This pilot calculates attendance-linked gross pay only. Verify a full shift, screen lock, departures/returns, offline checkout and your pay rules before using calculations for real salaries. Production has not received this feature.
