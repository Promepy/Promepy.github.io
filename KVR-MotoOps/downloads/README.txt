MotoOps India attendance pilot, build 2

Install MotoOps-India-Attendance-0.2.0-build2-arm64.apk on an ARM64 Android 13+ phone. It installs separately as MotoOps India Test. Sign in using your India account. Super Admin can configure Attendance and delegate scoped manager access. Configure store Maps pin/radius, rules, employee enrollment and effective salary before testing. Staff use Profile check-in/out and allow precise location.

Check-in requires internet. Encrypted observations queue during internet outages; checkout stops collection locally and syncs when connected. Force-stop, reboot and vendor battery restrictions can interrupt tracking. Restore monitoring from Profile when needed; unknown periods are recorded separately.

Verify a full shift, screen lock, departures/returns, offline checkout and your pay rules before using calculations for real salaries. Gross attendance-linked pay only. Production has not received this feature.
